# Jerome & Jomol — Wedding Invitation Website

A luxury digital wedding invitation web application celebrating the holy matrimony of **Jerome & Jomol** (`ജെറോം ♡ ജോമോൾ`) at **DAFFODILS Convention Centre**, Kozhikode, Kerala.

Built with React, Vite, and Tailwind CSS, featuring an authentic Kerala backwaters watercolor aesthetic, typewriter typography, ambient audio player, and interactive location navigation.

---

## 🌸 Key Features

1. **Kerala Watercolor Heritage Aesthetic**:
   - Full-width backwaters landscape painting with animated mist drift and soft feathered masks.
   - Traditional jasmine floral corners and lotus blessing ornaments.
   - Poetic Malayalam & English typography hierarchy (*Cormorant Garamond*, *Noto Serif Malayalam*, *Gayathri*, *Cinzel*).

2. **Full Section Narrative Hierarchy**:
   - **Hero Section**: Couple names, date rules, typewriter animation, and backwaters artwork.
   - **Our Story**: Featured couple portrait and romantic shared-horizon narrative.
   - **Wedding Details**: Date, Muhurtham time (10:30 AM), and venue summary.
   - **Festive Celebrations**: Holy Matrimony & Reception schedule with "Add to Google Calendar" buttons.
   - **Ceremony Venue & Map**: Dual-provider map (Google Maps & OpenStreetMap) with exact coordinates for Daffodils Convention Centre (`11.55937, 75.79857`) and instant turn-by-turn driving directions.
   - **Moments in Time**: 5-photo portrait-balanced gallery grid with high-resolution lightbox modal.
   - **Wedding Highlights / Film**: Cinematic video showcase.
   - **RSVP & Wishes Board**: Interactive RSVP responses and guest wishes board.

3. **Ambient Soundtrack Player**:
   - Floating audio widget at the bottom-left with animated soundwave equalizer bars, play/pause controls, and volume management.

4. **Smooth Autoscroll**:
   - Built-in cinematic auto-scrolling engine for showcases and kiosks.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/jithin-george123/wedding-invitation.git
cd wedding-invitation

# Install dependencies
npm install

# Start local development server
npm run dev
```

The site will be available at `http://localhost:3000/`.

### Production Build
```bash
npm run build
npm run preview
```
